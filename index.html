THE TURNTABLE NEURON

Three tracks (dendrites) bring trains to a turning platform. The turntable rotates, facing each track in turn: only what arrives while it faces that track rolls onto the platform (the soma). Once per rotation it faces the exit (the axon). If enough has gathered, carriages leave. Track length decides when each carriage arrives, so geometry decides which carriages count.
