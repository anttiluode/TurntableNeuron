THE TURNTABLE NEURON

Three tracks (dendrites) bring trains to a turning platform. The turntable rotates, facing each track in turn: only what arrives while it faces that track rolls onto the platform (the soma). Once per rotation it faces the exit (the axon). If enough has gathered, carriages leave. Track length decides when each carriage arrives, so geometry decides which carriages count. Everything before the exit is linear: the platform load is exactly the sum of these slot values. With the exit reading the load, this neuron computes only monotone threshold functions, never XOR. The green arrow in the turntable is z: every accepted piece of train adds the direction the turntable was facing. Read |z| at the exit and A (top) and C (bottom) can cancel; that is how the XOR preset works. Listeners are real yards whose turntables start at 34°, 304° and 214°, tuned to departures delayed by 8, 16 and 24 ticks. With the lock on (v4), each listener also gets the sender's pilot on a steering-only track, so its turntable follows the sender's rhythm: a common delay no longer moves the address, but jitter on the data itself still does. Wide windows (v5) are 90° instead of 45°: the addresses are 90° apart, so a window that wide survives ±3 to 4 ticks of jitter.
